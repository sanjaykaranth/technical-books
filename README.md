## Introduction to Program Synthesis (MIT 6.5130, Fall 2025)

`Intro_to_Program_Synthesis_MIT_6.5130_Fall2025.pdf` merges the lecture notes and slides of Armando Solar-Lezama's course into one booklet. Each lecture's web page is followed by its slide deck. Nothing was rewritten.
